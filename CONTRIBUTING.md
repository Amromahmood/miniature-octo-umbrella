# Contributing

Thanks for taking a look at the project.

## Getting started

1. Fork the repository.
2. Create a branch for your change.
3. Install the dependencies with `pip install -r requirements.txt`.
4. Run `python src/train.py` and then `pytest`.
5. Open a pull request with a short explanation of what changed and why.

## Good first contributions

Documentation improvements, additional tests, input validation, logging, and small reliability fixes are all useful contributions.

Please keep pull requests focused and avoid unrelated changes.
